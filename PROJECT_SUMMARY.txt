## 快速使用

### 查看文档
```bash
cat README.md                # 项目概况
cat QUICK_REFERENCE.md       # 快速参考
cat PROJECT_STRUCTURE.md     # 项目规范
cat CONTRIBUTING.md          # 贡献指南
```

### 部署项目
```bash
# 下载AI引擎
./scripts/deployment/download-engines.sh

# 启动Docker
docker-compose -f docker/docker-compose.local.yml up -d

# 查看日志
docker logs -f weiqi-game-server
```

### 本地开发
```bash
npm install
npm start
# 访问 http://localhost:9527
```
